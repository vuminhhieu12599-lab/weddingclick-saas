# Showroom asset provenance (LAUNCH-P0-04)

All files below were created in this repository for the public showroom. None is a photograph of a real person, a stock photo or a third-party asset. Fonts in the share image are Cormorant Garamond and Inter (SIL Open Font License 1.1), the same families the certified renderers already use.

## Demo mood images — `public/showroom/demo/`

Abstract bokeh and silk textures (no people, no faces), generated by `generate-demo-mood-images.py` in this folder (Pillow; fixed seeds, so the output is reproducible on the same Pillow version):

```sh
python3 lib/showroom/demo/generate-demo-mood-images.py public/showroom/demo
```

They fill the demo couple's photo slots only (`demo-media.ts`). Person-bound portrait slots stay empty on purpose, so the template shows its real no-portrait layout instead of an abstract image posing as a person. They are never a fallback for a real Project.

**Replacing them with licensed demo photography** (recommended before marketing at scale): add the licensed files to `public/showroom/demo/`, update `DEMO_IMAGES` in `demo-media.ts` (file, width, height, orientation), re-capture the template screenshots (below) and record the licence here. No other code changes.
