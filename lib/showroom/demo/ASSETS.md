## Demo bank-QR plates — `public/showroom/demo/`

Two 600×600 lossless WebP QR symbols (version 3, error correction level M, byte mode, near-black on white), generated by `generate-demo-qr-images.py` in this folder. The script carries its own encoder, so the repository gains no dependency, and it is deterministic:

```sh
python3 lib/showroom/demo/generate-demo-qr-images.py public/showroom/demo
```

**They are not payment codes.** Each encodes one plain ASCII line and nothing else — `WEDDINGCLICK THIEP MAU - NHA TRAI` and `WEDDINGCLICK THIEP MAU - NHA GAI` — so scanning one shows that sentence and can start no transfer. They stand in for the couple's own `QR_GROOM` / `QR_BRIDE` media in public demos only, alongside the openly fictional "Ngân hàng Demo (thiệp mẫu)" and account numbers 0000000001 / 0000000002, and are never a fallback for a real Project.

Wired in `demo-media.ts` as `DEMO_QR_IMAGES` and referenced from the demo `wedding_details` in `demo-wedding-source.ts`, so every renderer that resolves `media.qr.<side>` shows the plate for each operational side (no common QR). Each symbol was verified by an independent decoder (OpenCV `QRCodeDetector`) to decode back to its exact payload.
