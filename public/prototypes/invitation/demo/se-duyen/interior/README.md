# Se Duyên — Pilot v0.3 interior sections (photos)

Prototype review only. **Not approved production assets.**

Both files are **byte-identical copies** of approved fictional demo photography
already in this repository (`public/showroom/demo/vietnamese-heritage/photos/`).
Nothing was redrawn, re-rendered or re-encoded, and the showroom originals were
not touched — the copies exist so the internal prototype does not read from the
public showroom tree.

Only four of the ten approved Vietnamese-heritage photos are usable in this
direction: `01`, `02`, `03` and `10`. The rest are excluded on sight —
`05`, `06`, `08` and `09` carry a 囍 double-happiness glyph, which Se Duyên

couple section) re-cropped so they do not read as repeats.
