its area:

| HTTP routes, RPCs, activity log | `API_CONTRACT.md` |
| Running the pilot in Production | `PILOT_OPERATIONS_RUNBOOK.md` |
| Past decisions (search, don't read whole) | `DECISIONS.md` |

`LEGACY_AUDIT.md`, `TASK-000-CLAUDE-AUDIT.md`, `WeddingClick_AI_HANDOFF.md`) describe
the earlier heavyweight checkpoint process. Where they conflict with `../CLAUDE.md`,
`CLAUDE.md` wins.
