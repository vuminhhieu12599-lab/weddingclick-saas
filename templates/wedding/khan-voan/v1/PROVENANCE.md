# Khăn Voan v1 — provenance

- **Design:** authored for WeddingClick by Claude with the Product Owner, 2026-11-27
  (approved preview: veil-lift opening, ivory satin paper, framed story photos,
  magazine album, gift box popup).
- **Artwork:** every decoration (monogram wreath, lace edge, vine, rings, heart,
  satin bow, gift box, satin paper texture, gold flecks) is original inline
  vector or CSS drawing in this directory. There are no image asset files and no
  third-party artwork.
- **Fonts:** Lora, Be Vietnam Pro and Imperial Script — SIL Open Font
  License 1.1, self-hosted through `next/font/google` with the `vietnamese` subset.
- **Photos:** none ship with the renderer. Showroom demo photos are the existing
  fictional Elegant Editorial set (`public/showroom/demo/elegant-editorial/`).
